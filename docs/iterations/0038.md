## 任务 01 让静态凭据拒绝短暂停用该连接

状态 `PASS`

- `gateway` 对已使用静态 key 的上游 HTTP 401 设置 60 秒进程内避让，覆盖该源所有模型。代理页沿用 `credential-rejected`，记录下一次可尝试时间。到期自动重新尝试。成功保存或清除 key 后立即解除避让。
- `manifest` 运行态增加非持久化的避让时间。借用既有连接版本防止旧响应限制新 key。OAuth 继续走刷新路径，账号与模型额度状态和手动暂停按原规则生效。Provider 手动探测仍可直接发起。
- Rust 回放验证同源多模型只撞一次 401、后续跳过、保存新 key 恢复及旧快照兼容。真实 OpenCode 与本机上游回放验证免费首源拒绝、订阅兜底和新 key 恢复。然后跑全量门禁。
