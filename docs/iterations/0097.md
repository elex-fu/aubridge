### 操作合同

- 托盘直接操作已有 `GatewayState` 软开关，和现 Web Admin 共用同一事实来源。不得创建第二份 serving 布尔、落盘新设置或改成重启保持暂停；不调用外网，不新增凭据传递，不写用户 agent 配置。

- 通知方案固定采用现有 Tokio `watch`，不使用轮询。`GatewayState.serving` 由 `RwLock<bool>` 替换为唯一 `watch::Sender<bool>`，初始化 true；`is_serving()` 读取 sender 当前值，`set_serving(on)` 使用 `send_replace(on)`，保证无 receiver 时也更新事实；新增 `subscribe_serving() -> watch::Receiver<bool>`。不保留第二份状态，HTTP 合同不变。
- 原生托盘安装取得 receiver，先读取当前值初始化菜单，再监听 `changed()`；通过 Tauri 主线程更新现有菜单项，并仅向 `main` 发 `aubridge-serving-changed` 事件，payload 是单一 boolean，不含 token/地址/请求数据。事件监听任务与应用生命周期绑定，退出 drain 开始时禁止切换且禁用菜单；异步回调写菜单前再次核对退出阶段，不能被排队的旧通知重新启用。重复同值不导致多次业务动作。
- `tauri.conf.json` 已确认 `withGlobalTauri: true`，但目前没有 capability，不能假设自定义 `gateway_access` 可用就代表 core event 可监听。新增内部最小 `crates/smoke/capabilities/main-events.json`，只匹配本地 `main` window，权限仅 `core:event:allow-listen` 和 `core:event:allow-unlisten`；不添加 remote URL、不授予前端 emit 或其它 core 默认权限。本地 `gen/schemas/acl-manifests.json` 已核两权限对应 listen/unlisten。此文件是应用内部 ACL，不是新用户配置。
- Web 在 api.ts 增加窄 typed `window.__TAURI__.event.listen<boolean>` 封装；Proxy 挂载先注册 listener，再加载初始页面，事件仅修改 `serving` 投影，绝不重跑历史查询、不清筛选或分页。注册期间收到的最新 boolean 独立保存到组件 ref，使迟到初始 GET/历史分页响应不能覆盖较新的事件值；旧 load 响应中 serving 与历史数据分别处理。组件卸载解除监听，异步注册完成时若已卸载立即 unlisten，避免切页累积。listener 注册失败明确报同步错误，不能静默冒充实时同步；真实 native WebView 是 ACL 是否生效的硬验收。
- 原生 listener 先订阅后取初值，Web listener 先建立后读取快照；读取与事件并发时采用上述“最近事件覆盖旧快照”边界。网页 Admin 更改同一个 setter，自然通知 native；托盘更改也通知打开的 Proxy。无需额外 endpoint、WebSocket、轮询或通用总线。
