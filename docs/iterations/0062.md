- RESTART_EXIT_CODE 原样放行，不能假设 prevent_exit 能拦截；维持 RunEvent::Exit 的最终刷新兜底。窗口关闭仍在有托盘时隐藏，Reopen 和托盘展示不变。非 macOS 只涉及既有托盘路径，不重建其菜单。
- 监听关闭、实例锁维持至排空完成、5 秒期限及持久化顺序直接使用 0053 实现，不另设超时或改写结算语义。
