## 任务 01 单源暂停和恢复

状态 `PASS`

- Provider 页提供“暂停推理”和“恢复推理”。本机管理 API `POST /admin/providers/{id}/pause` 要求管理凭据和布尔字段 `paused`。配置中的暂停名单可为空，旧配置默认所有源沿用原状态。用现有原子写保存，串行化同一网关内的配置修改，失败时保持运行态。删除自定义源同步移除对应暂停项。
- 在候选预检、尝试前和订阅槽位等待后检查暂停。暂停源跳过并记录 `provider-paused`，其凭据、配置、模型发现和上游冷却仍由原机制管理。恢复后重新参与正常免费优先路由。已经出站的流允许结束。手动连接检测仍由用户显式触发。
- 回放验证管理鉴权、暂停后无推理出站、同组免费源仍可用、持久化、恢复以及排队中的请求跳过暂停源。通过真实 OpenCode 连接隔离网关，验证切换前后由不同候选应答。按要求跑前端构建、fmt、Clippy 和工作区测试。
