- 复用现有 Agents 编辑弹层和 Admin 模型设置路径，仅在 OpenCode 已接线、配置仍受管时开放编辑。当前未受管默认明确显示“沿用 OpenCode 原默认”，不得把列表首项或自动路由误作已经选中。取消编辑零写入；显式保存成功后刷新显示实际选择，失败保留原值并给可读错误。
- 选择范围复用网关已知模型、自动别名与既有分组；落盘值为 `aubridge/<网关模型 ID>`，保留模型 ID 内部斜杠。受管模型投影仅剥除一个 provider 前缀，UI/Admin、供应保护统一使用网关 ID，避免 `aubridge/aubridge` 自动别名或带斜杠模型被截错。
- OpenCode 实现真实 `current_model`/`set_model`，Admin 不再 no-op 成功。未接线、路径变化、Provider 外部漂移或 model 外部漂移拒绝写入；只在可证明仍受管时认定受管模型引用。用户原有 foreign 默认不算本应用引用，不能阻挡无关模型删除。
- 初次接线、启动修复、端口更新、目录同步均不选择或覆盖顶层 model。首次显式选择前保存当时的原 model 原始值/缺省状态，再字段级写入所选值。再次选择只更新受管值，不覆盖首次原值；端口和目录同步也不得重置首次 model 或 Provider 备份。
