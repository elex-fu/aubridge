## 任务 01 完整无 data 帧不产生数据事件

状态 `PASS`

- 在现有 proto SSE 解析器的完整空行边界，仅当本帧实际存在至少一个 data 字段时生成 RawSseEvent。无 data 的 event 标签、注释、id/retry 和其他控制字段均不生成数据事件。
- 每个完整空行边界必须清除本帧 event 标签，即使本帧没有 data；不能让 `event: error` 或其他标签泄漏到随后无标签的合法数据帧。已有多 data 行的换行拼接、字段空格规则和含 data 帧的标签补齐保持。
- 严格区分“没有 data 字段”和“显式空 data 字段”：`data:`、`data: ` 及无冒号的 `data` 仍计为存在 data 字段，仍走原有解析/坏 JSON 处理，不通过跳过空字符串把上游坏数据伪装成控制帧。空白 JSON 或畸形 JSON 的既有错误语义不变。
- 仅调整完整帧边界，不扩大 EOF 宽容。未终止帧的 incomplete 报告与网关 FrameReader 的截断错误规则保持；无 data 控制帧不是成功结束、正文、用量或拒答，不改变首段预算、F-5、终态要求和路由状态。
- 保持现有 LF、CRLF 支持、注释保活与原生路径的控制字节处理；不新增保活计时、内容恢复、编码处理或统一解析框架。范围限于 proto 的完整帧事件产生条件、必要定向回归及产品设计说明，网关仅在确有必要时最小适配。
