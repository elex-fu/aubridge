## 任务 01 两处展示使用同一受管客户端范围

状态 `PASS`

- 复用现有 `supportsWiring` 的 Claude Code、OpenCode、Codex 三项判断，必要时将现有函数移到可共享位置；不另建客户端名单、状态缓存或检测服务。Gemini 仍不在桌面支持接线的范围，不能因检测到或其他返回值而进入摘要计数或使引导消失。
- Agents 接线引导判断“是否没有任何支持的客户端已接线”。任一支持客户端 wired 后不再显示“源已就绪——在下方接线一个 agent”；全无接线仍显示。仅 detected 不能算已接线。保留 configured 门控和原有缺 Key、全部暂停提示及其优先关系，不能因已有客户端接线而隐藏源未就绪的提示。
- Provider 摘要列出支持接线且 detected 的客户端，以同一展示集合中的 wired 项计算“已接线 N 个”，避免列表与计数口径不同。检测到但未接线者仍列出、计数为零；全无符合项保留未检测到的说明。仅是据当前配置检测的本机客户端摘要，不宣称每个 Provider 被这些客户端实际调用，也不统计订阅账号。
