# aubridge 品牌图标设计

日期：2026-11-12。状态：设计定稿，资产生成与原生展示验收分别记录。

## 定位与范围

依据 `product-design.md` §1–3 与 `ui-design.md`：aubridge 是单机、单用户的桌面模型代理，把官方免费源与用户自有订阅接给本机 Agent，免费优先、订阅兜底，凭据和诊断留在本机。品牌表达是安静、可信、流畅的连接；不暗示共享账号、云中转或金融服务。

本次用户追加要求覆盖软件 Logo、程序坞、Finder/桌面与系统托盘。采用唯一方案“线桥”：一条对称流线拱与一条水平桥面相交，拱顶和中间横画轻带 A 的轮廓，但不把字母塞进图形，也不对 aubridge 名称的词源作解释。桥面的平稳与拱线的连续表达连接和切换；这些是品牌意象，不是新增产品承诺。

仅更换品牌资产及必要的桌面壳资源引用。业务逻辑、托盘菜单与事件、窗口关闭和退出行为保持原契约；窗口继续默认 800×480、最小 760×480、不最大化。本文不启动 0098，不增加通过计数。0097 原生托盘交互验收仍为 `BLOCKED`，累计 4 / 10；Logo 完成不能替代它。

## 权威几何

生产 SVG 是权威源，PNG/ICNS/ICO 为派生文件。统一基础坐标 `viewBox="0 0 64 64"`，仅两条开放路径，无文字、节点、星光、电路线、立柱吊索或水面：

```svg
<g fill="none" stroke="currentColor" stroke-width="4"
   stroke-linecap="round" stroke-linejoin="round">
  <path d="M12 44 C20 44 20 20 32 20 C44 20 44 44 52 44"/>
  <path d="M12 36 H52"/>
</g>
```

左右严格镜像；路径交叉不打断、不扣白、不加描边。拱顶切线水平，桥脚向两侧自然舒展；大图仍只保留两笔，小图不会退化成复杂栅格。彩色版笔画宽 4，外接绘制范围约 x=10–54、y=18–46，几何中心 (32,32)。不得单独拉伸横轴或纵轴。

推荐生产源位置 `crates/smoke/icons/bridge-mark.svg`。生成脚本从此源读取两条 path，构造下述 app/tray SVG；不得在脚本、Rust 和多个 SVG 中手工维护不同桥形。生产 SVG 文件由实现者落盘。

## 彩色应用图标

外画布 64×64、透明。圆角底板 `<rect x="4" y="4" width="56" height="56" rx="13"/>`，形成 6.25% 外围透明留白。桥形原位绘制，不另加缩放；距离底板最窄处仍有 6 单位净距。

| 元素 | 精确定义 |
|---|---|
| 底板 | 深青墨渐变：`#18333A` → `#0C2027` |
| 底板渐变坐标 | `gradientUnits="userSpaceOnUse" x1="32" y1="4" x2="32" y2="60"`，两个 stop 为 0%、100% |
| 桥形 | 温润浅金渐变：`#F8E6C1` → `#D6AA72` |
| 桥形渐变坐标 | `gradientUnits="userSpaceOnUse" x1="12" y1="20" x2="52" y2="44"`，两个 stop 为 0%、100% |
| 颜色插值 | SVG 默认 sRGB，不透明 stop，无滤镜 |
| 单色备用 | 桥形 `#EACB98`，底板 `#112A32` |

同一个桥形渐变用于两条 path；用 userSpaceOnUse 避免水平路径零高度导致渐变失效。不要立体高光、发光、外阴影、边框、反射、浮雕或贴字。底板自身留白/圆角已经完成图标轮廓，不再在导出工具里二次包一层底板。该深色应用图标在系统明暗外观均使用同一版。

派生彩色 SVG 建议位置 `crates/smoke/icons/app-icon.svg`。标准 PNG 输出 16、32、48、64、128、256、512、1024；`icon.png` 使用 1024×1024。macOS `icon.icns` 包含 16/32/128/256/512 的 1×/2×表示（包括 1024）；Windows `icon.ico` 至少含 16/24/32/48/64/128/256。若官方工具有平台固定文件名，可沿用工具命名，保持源与产物对应可追溯。

## 系统托盘

托盘不使用彩色底板和金色，不显示文字。使用透明背景、纯黑 RGB 与抗锯齿 alpha 的模板图标；macOS 通过模板着色适配浅色、深色和选中状态。现有 `icon_as_template(true)` 保留。

沿用两条权威 path，仅允许以下光学校正：笔画宽改为 `4.8`，整体应用 `transform="translate(-4 -4) scale(1.125)"`，viewBox 仍为 0 0 64 64。即以中心 (32,32) 放大 1.125 倍。绘制范围约 x=6.8–57.2、y=15.8–48.2；在 18px 画布上左右各约 1.9px 空白，视觉宽约 14.2px、有效笔画约 1.5px，拱顶与桥面之间仍有清晰负空间。

派生 `tray-icon.svg`、`tray-icon.png`（18×18）与 `tray-icon@2x.png`（36×36）。运行时加载 36×36 alpha 模板，显示为 18pt；18px版本用于普通密度检查。不允许继续用 Rust 手写二值像素 mask。16px 校验也从同一模板 SVG 导出，只作为更小尺寸检查，不改变正式托盘逻辑尺寸。不以颜色承载暂停/恢复状态；状态继续由已有菜单及提示表达。

## 实施落点

- `crates/smoke/icons/`：权威桥形 SVG、派生 app/tray SVG、PNG/ICNS/ICO。
- 最小的本地资产生成脚本：读取 SVG 几何，确定性派生 SVG 与平台资产；优先使用已安装的 Tauri 官方 icon 命令，不引入运行时依赖。
- `crates/smoke/tauri.conf.json`：bundle.icon 指向生成的 PNG/ICNS/ICO；窗口参数保持当前值。构建前端命令只在确有目录问题时做必要修正。
- `crates/smoke/src/main.rs`：仅以嵌入 PNG 替代临时像素图生成，保留托盘标识、模板设置、菜单、监听和生命周期逻辑。
- 本机可运行 `.app`：检查 `Contents/Info.plist` 中 `CFBundleIconFile` 与实际 `Contents/Resources/*.icns` 对应。仅换仓库 PNG 不等于程序坞或桌面已更新。
- 本机安装及桌面入口：将本次开发应用放到 `~/Applications/aubridge.app`，桌面创建指向该包的入口；若目标已存在须核实来源并保留用户已有内容，不覆盖未知应用。程序坞由这个实际应用包启动显示，不用网页图标或独立图片冒充。开发包及本机运行证据不构成签名、公证或发行验收。

## 验收与证据边界

1. **资产检查**：SVG path 与上述权威几何一致；尺寸、RGBA alpha、外围透明、ICNS/ICO 帧齐全。独立导出能重现资产。模板非透明像素 RGB 统一黑色，灰阶来自 alpha。
2. **视觉检查**：彩色图以 16/32/64/128/512px，托盘以 16/18/36px 在白色 `#FFFFFF`、浅灰 `#ECEDEF`、深色 `#16191D` 背景上按实际尺寸查看。两笔连续、左右平衡、拱与桥面间留有负空间，无毛边、裁切和变形。托盘深色背景预览要按模板着色为白色，不能误把黑色原图直接贴上去当系统效果。
3. **原生展示**：在真实 macOS 运行本次 `.app`，分别核对 Finder/桌面入口、正在运行的 Dock 图标、菜单栏模板图标。记录应用路径、实际二进制和资源归属。截图/观察证明展示，资源存在仅证明打包；若菜单栏不可操作，准确保留该限制。
4. **范围检查**：窗口仍为 800×480/min760×480/非最大化；业务源文件不动。按实际改动运行必要构建及 Rust 检查，不为静态图形增加镜像实现测试或额外真实上游调用。
5. **独立状态**：报告分开列出品牌资产、打包资源、实际 Dock/Finder/桌面、实际菜单栏展示。即使这些通过，0097 暂停/恢复、关闭/重开、退出及事件同步的旧验收仍保持原状态，不把图片变更当原生托盘交互通过。
